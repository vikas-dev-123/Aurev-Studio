# North & Fern — Premium Agency Landing Page

A production-ready React + Vite + TypeScript + Tailwind CSS landing page for a digital systems studio.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize

- Brand name: `src/components/Navbar.tsx`, `index.html`
- Email: `src/components/Contact.tsx`
- Hero video: `src/components/VideoBackground.tsx`
- Services/modules: `src/components/Services.tsx`, `src/components/Systems.tsx`
- Visuals: `src/components/VisualShowcase.tsx`
- Colors: `src/index.css` and `tailwind.config.ts`

## Stack

React 18 · TypeScript · Vite · Tailwind CSS · Framer Motion · GSAP-ready architecture · hls.js · Lucide React · shadcn-style UI patterns
